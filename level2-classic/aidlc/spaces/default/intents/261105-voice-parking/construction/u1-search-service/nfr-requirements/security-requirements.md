| ID | 요구사항 | 측정 방법 | 출처 |
|---|---|---|---|
| NFR6.1 | 이 서비스는 비밀 값이나 자격 증명을 가지지 않는다. 소스 코드와 설정에 비밀 값이 하나도 들어 있으면 안 된다. | 소스와 설정 파일에서 비밀 값 패턴 검색 결과 0건 | NFR6, 보안 규칙 |
| NFR6.2 | 모든 입력은 시스템 경계에서 검증한다. 본문 `text`는 비어 있지 않고 200자 이하, `X-Session-Id`는 UUID 형식, C4의 `durationHours`는 1 이상의 정수여야 하며 어긋나면 400을 돌려준다. | 잘못된 입력별 단위 시험 | NFR6, BR1.5, BR1.6, BR4.2 |
| NFR6.3 | 입력 문장은 장소 이름 일치와 숫자 추출에만 쓰고 실행하거나 쿼리로 해석하지 않는다. 오류 응답에 입력 원문을 그대로 되돌려 보내지 않는다. | 특수문자·긴 문자열 입력 시험 | NFR6 |
| NFR6.4 | 인증과 인가는 없다. 세션 ID는 식별용이며 이 서비스는 읽기 전용 목업 데이터만 다루므로 세션별 접근 통제가 필요 없다. 인증을 우회하는 코드는 만들지 않는다. | 설계 확인 | NFR6, Q4 |
| NFR8.1 | 서비스 간 호출 주소는 환경 변수로 주입하며 코드에 하드코딩하지 않는다 (이 서비스는 다른 서비스를 호출하지 않으므로 해당 사항이 없을 수 있다). | 설정 검토 | NFR8 |
