# u1-search-service 논리 구성 요소

## Sources

- [scope] Workflow-selected scope: classic
- [memory:M1] unit-of-work.md(U1), components.md(QueryParser, Recommendation), nfr-design의 성능·보안·신뢰성·관측성 설계

서비스 하나(프로세스 하나) 안의 논리 구성 요소를 적는다.

| 구성 요소 | 책임 | 적용되는 NFR 설계 |
|---|---|---|
| 웹 계층 | C1·C4 요청을 받아 입력을 검증하고 응답을 만든다 | 경계 입력 검증(보안), 전역 예외 처리(신뢰성) |
| 요청 로그 필터 | 모든 요청의 경로·상태·시간을 기록한다 | 관측성 |
| QueryParser | 문장에서 장소와 이용 시간을 추출한다 (컴포넌트 QueryParser) | 입력 원문 비반사(보안) |
| Recommendation | 후보 수집, 제외, 점수 계산, 정렬, 이유 생성, 주차권 조회 (컴포넌트 Recommendation) | 메모리 계산, 정수 반올림(성능) |
| 목업 데이터 저장소 | 시작 시 적재한 불변 주차장·주차권과 장소별 색인 | 빨리 실패하는 적재(신뢰성), 시작 시 메모리 적재(성능) |
| 상태 확인 | `/actuator/health` | 관측성 |

## 실패 영역과 영향 범위

- 서비스 전체가 하나의 실패 영역이다. 이 서비스가 죽으면 u4 화면의 추천과 u2의 예약 생성(주차권 조회)이 실패한다. 이미 만들어진 예약의 결제·확정·취소는 이 서비스에 의존하지 않아 영향이 없다.
- 공유 자원은 없다. 데이터는 이 서비스의 프로세스 메모리에만 있고 다른 서비스와 공유하지 않는다.
