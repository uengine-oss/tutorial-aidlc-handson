# u5-local-run 단위 시험 안내

## 시험 틀과 준비

- 시험은 bash 스크립트다. 추가 설치가 필요 없다(`bats`, `shunit2`를 쓰지 않는다). 가짜 서비스는 셸 래퍼와 Node 서버(`scripts/test/fakes/`)다. 필요한 도구: `/bin/bash`(3.2), `node`, `curl`, `lsof`, `openssl`(없으면 `od`로 대체하는 경로도 시험한다).
- 시험은 반드시 `/bin/bash`(macOS 기본 3.2)로 실행한다. 시험마다 저장소 안 임시 작업 폴더(`.local-run/test-work/`)를 쓰고 끝나면 지운다. `/tmp`를 쓰지 않는다.
- 시험은 실제 `mvn`·`npm`을 부르지 않는다. 가짜 명령과 가짜 서비스를 환경 변수로 주입한다. 실제 서비스를 띄운 연동 확인은 Build and Test의 몫이다.

## 이 유닛의 시험 실행 명령

```bash
/bin/bash scripts/test/run-local.test.sh
```

이 명령이 첫 시험 주기 전에 실행 가능해야 한다(Step 2). 나머지 단위 범위 명령:

```bash
/bin/bash scripts/test/smoke-local.test.sh
/bin/bash scripts/test/verify-all.test.sh
```

## 커버리지 측정과 하한

```bash
/bin/bash scripts/test/coverage.sh
```

- 대상은 `scripts/run-local.sh`다. 모든 시나리오를 `SHELLOPTS=xtrace`와 `PS4='+TRACE|${BASH_SOURCE}|${LINENO}|'`로 돌려 줄별 실행 여부를 모은다.
- 하한은 줄 커버리지 80%다. 이 하한은 낮추지 않는다. 분모 제외 규칙은 `coverage.sh` 한곳에만 있고 `code-summary.md`에 목록으로 적는다. 하한은 이 유닛 전체 시험으로 판정하는 값이며 Build and Test가 전체 시험에서 다시 확인한다.
- 이 명령은 하한 미달일 때만 0이 아닌 종료 코드로 끝난다. 다른 확인을 뒤에 두지 않고 이 명령 단독으로 실행한다.
- 측정은 근사다: 한 줄 안의 조건 분기는 세지 못한다.

## 전체 시험

```bash
/bin/bash scripts/test/run-all.sh
```

일반 시험(비밀 값 출력·로그·인자 확인 포함), 스모크·검증 스크립트 시험, `bash -n` 검사, `shellcheck`(있으면), 커버리지 측정을 차례로 실행한다. 커버리지 실행은 비밀 값 비출력 확인을 건너뛰고(`COVERAGE=1`) 고정 가짜 비밀 값을 쓴다. 비밀 값 확인은 일반 실행에서만 한다.

## 모킹과 시험 데이터

- 가짜 서비스(`fake-service.sh`)는 동작 모드를 환경 변수로 받는다: 정상, 즉시 종료, 준비 안 됨, SIGTERM 무시, 자식·손자 생성, 나중에 종료. 자기 환경과 인자를 파일에 남겨 시험이 확인한다.
- 가짜 서버(`fake-server.js`)는 `/actuator/health`, `/`, `POST /api/search/recommendations`(400), 웹훅·내부 경로(404), 스모크용 추천·결제·예약 응답을 낸다.
- 시험용 포트는 기본값 대신 환경 변수로 비어 있는 포트를 쓴다. 시험용 비밀 값은 시험 안에서 만든 고정 가짜 값이며 실제 비밀 값이 아니다.
- 시간 제한(준비 90초, 유예 10초, 감시 2초)은 환경 변수로 줄여 시험한다. 실제 기본값 자체는 설정 구역 시험이 확인한다.

## 예상 시험 수

시나리오 약 40개. Minimal 전략의 요구사항별 시험 하나 이상과 구성 요소(함수)별 정상 경로 하나 이상을 채운다.
