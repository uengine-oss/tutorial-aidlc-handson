## 장애 시 동작

| 장애 | 동작 |
|---|---|
| u1-search-service 중단·지연 | 예약 생성이 502 UPSTREAM_FAILED. 예약은 만들어지지 않는다. 호출자가 같은 키로 다시 요청할 수 있다 |
| 구독 연결 끊김 | 그 구독만 제거. 화면은 같은 URL로 재연결하면 최신 스냅샷을 다시 받는다 (BR4.3) |
| 이 서비스 재시작 | 모든 예약이 사라진다. 결제 대기였던 예약의 승인은 404가 되고 사용자는 처음부터 다시 진행한다 (NFR5.7) |
| u3가 결과 반영 호출을 못 함 | 이 서비스에는 영향이 없다. 승인이 유실되면 예약은 마감 시각에 자동 취소된다 (contract-summary.md C6) |
| 타이머 지연 | NFR2.3. 도착하는 결과가 시계로 마감을 판정한다 |
