# Accessibility Checklist

## Sources

- [scope] Workflow-selected scope: classic
- [Q3] 데스크톱 중심, 키보드 조작과 색 대비 같은 기본 접근성 (WCAG 2.1 AA 전체와 모바일 반응형은 이번 범위가 아님)
- [memory:M1] mockups.md의 화면 S1~S8, interaction-spec.md

## 범위

사용자가 데스크톱 중심 + 기본 접근성을 선택했다. 아래 항목만 이번 프로토타입의 합격 기준으로 삼는다. WCAG 2.1 AA 전체 준수는 목표가 아니다.

## 체크리스트

| 번호 | 항목 | 통과 기준 | 화면 |
|---|---|---|---|
| A1 | 키보드 조작 | 모든 입력창과 버튼을 Tab 키로 순서대로 이동하고 Enter로 실행할 수 있다 | S1~S8 |
| A2 | 포커스 표시 | 포커스된 요소에 눈에 보이는 윤곽선이 있다 | S1~S8 |
| A3 | 색 대비 | 본문 글자와 배경 대비 4.5:1 이상 | S1~S8 |
| A4 | 색에만 의존하지 않기 | 오류, 실패, 취소는 색뿐 아니라 문구 또는 아이콘 문자로도 표시한다 | S2, S7, S8 |
| A5 | 입력창 레이블 | 입력창에 화면 낭독기가 읽을 수 있는 레이블이 연결되어 있다 | S1 |
| A6 | 상태 변화 알림 | 결제 상태가 바뀌면 화면 낭독기에 알려지도록 aria-live 영역을 쓴다 | S5, S6, S7, S8 |

## 열린 항목

- 모바일(폭 360px) 레이아웃과 확대/축소 대응은 이번 범위에서 제외한다. 필요하면 이후 요구사항으로 추가한다.
