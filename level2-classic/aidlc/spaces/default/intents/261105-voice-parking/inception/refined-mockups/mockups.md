## 화면 구성

한 페이지(단일 화면) 안에서 상태가 바뀌는 구조다. 상단의 입력 영역은 항상 보이고, 아래 결과 영역이 상태에 따라 바뀐다.

| 화면 상태 | 스토리 | 설명 |
|---|---|---|
| S1 입력 대기 | US1.1 | 입력창과 전송 버튼, 예시 문구 |
| S2 해석 오류 | US1.1 | 장소 또는 시간이 빠졌다는 안내 |
| S3 추천 결과 | US2.1, US2.2 | 최적 1개 + 비교 후보 2개, 추천 이유 |
| S4 후보 없음 | US2.1 | 조건에 맞는 주차권 없음 안내 |
| S5 결제 승인 대기 | US3.1 | 선택한 주차권 요약, 대기 안내와 경과 시간 |
| S6 예약 완료 | US4.1 | 주차장, 이용 시간, 결제 금액 |
| S7 결제 실패 | US3.2 | 실패 안내, 같은 목록의 다른 후보 재선택 |
| S8 자동 취소 | US4.2 | "승인 지연으로 예약이 취소되었습니다" |

## S1 입력 대기 (US1.1)

```
+--------------------------------------------------------------+
|  VoiceParking                                                |
|                                                              |
|  어디서 몇 시간 주차할지 말해 주세요                              |
|  [ 강남역 근처 2시간 주차권 찾아줘                 ] [ 전송 ]   |
|  예: "강남역 근처 2시간 주차권 찾아줘"                          |
+--------------------------------------------------------------+
```

- 입력창은 한 줄이고 엔터 키로도 전송된다.
- 빈 입력이면 전송 버튼이 비활성이다.

## S2 해석 오류 (US1.1)

```
+--------------------------------------------------------------+
|  [ 2시간 주차권 찾아줘                              ] [ 전송 ]   |
|  (!) 장소를 알려 주세요. 예: "강남역 근처 2시간"                  |
+--------------------------------------------------------------+
```

- 장소가 없으면 "장소를 알려 주세요", 시간이 없으면 "이용 시간을 알려 주세요"를 보인다.

## S3 추천 결과 (US2.1, US2.2)

```
+--------------------------------------------------------------+
|  [ 강남역 근처 2시간 주차권 찾아줘                 ] [ 전송 ]   |
|                                                              |
|  최적 추천                                                    |
|  +--------------------------------------------------------+  |
|  | 강남역 공영주차장            종합 92점                   |  |
|  | 2시간 6,000원 · 도보 120m · 2시간 이용 가능              |  |
|  | 이유: 가격이 가장 큰 강점 (가격 40 · 거리 32 · 시간 20)   |  |
|  |                                          [ 이 주차권 결제 ]|  |
|  +--------------------------------------------------------+  |
|  비교 후보                                                    |
|  +----------------------------+ +----------------------------+|
|  | 역삼 빌딩 주차장   72점     | | 테헤란로 주차장     65점   ||
|  | 2시간 7,000원 · 80m        | | 2시간 5,000원 · 300m       ||
|  | 이유: 거리가 가까움         | | 이유: 가격이 낮음           ||
|  |            [ 이 주차권 결제 ]| |            [ 이 주차권 결제 ]||
|  +----------------------------+ +----------------------------+|
+--------------------------------------------------------------+
```

- 점수 위 숫자는 예시이며 실제 값은 목업 데이터와 점수 계산으로 결정된다.
- 이유 문구에는 기여가 가장 큰 항목명(가격/거리/시간 적합도)을 반드시 넣는다 (AC2.2.5).
- 후보가 3개 미만이면 있는 카드만 보인다.

## S4 후보 없음 (US2.1)

```
+--------------------------------------------------------------+
|  조건에 맞는 주차권이 없습니다. 장소나 시간을 바꿔 다시 말해 주세요. |
+--------------------------------------------------------------+
```

## S5 결제 승인 대기 (US3.1)

```
+--------------------------------------------------------------+
|  결제 승인을 기다리는 중입니다...                                |
|  강남역 공영주차장 · 2시간 · 6,000원                            |
|  경과 42초 / 최대 180초                                        |
+--------------------------------------------------------------+
```

- 다른 후보의 "이 주차권 결제" 버튼은 비활성이다 (세션당 결제 대기 1건, AC3.1.3).
- 경과 시간은 1초마다 갱신된다.

## S6 예약 완료 (US4.1)

```
+--------------------------------------------------------------+
|  예약이 완료되었습니다                                          |
|  강남역 공영주차장                                              |
|  이용 시간 2시간 · 결제 금액 6,000원                            |
|                                         [ 새로 검색하기 ]      |
+--------------------------------------------------------------+
```

- 승인 웹훅 수신 후 1초 이내에 S5가 S6으로 바뀐다 (NFR1).

## S7 결제 실패 (US3.2)

```
+--------------------------------------------------------------+
|  (!) 결제가 거절되었습니다. 다른 주차권으로 다시 결제할 수 있습니다.   |
|  [추천 목록 다시 보기: 같은 3개 카드, 실패한 카드는 "결제 실패" 표시] |
+--------------------------------------------------------------+
```

- 실패한 후보를 다시 고를 수 있는지는 요구사항에 정해지지 않아 열린 질문으로 남긴다. 목업은 실패한 카드의 버튼을 비활성으로 보여 준다. [assumption]

## S8 자동 취소 (US4.2)

```
+--------------------------------------------------------------+
|  (!) 승인 지연으로 예약이 취소되었습니다.                         |
|                                         [ 다시 검색하기 ]      |
+--------------------------------------------------------------+
```

## 열린 질문

- 결제 실패 후 같은 후보를 다시 고를 수 있는지, 실패 뒤 도착한 승인 웹훅 처리는 도메인 설계에서 정한다.
