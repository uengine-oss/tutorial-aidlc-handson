## 화면 상태별 처리

| 상태 | 로딩 | 빈 상태 | 오류 |
|---|---|---|---|
| 추천 요청 | 전송 후 결과가 오기 전까지 버튼 비활성과 "찾는 중..." 문구 | S4 | 서버 오류면 "잠시 후 다시 시도해 주세요" 안내와 다시 전송 가능 |
| 결제 대기 | S5의 대기 문구와 경과 시간 | 해당 없음 | SSE 연결이 끊기면 자동 재연결 후 같은 예약의 현재 상태를 다시 받아 표시 (AC4.1.4) |

## 실시간 갱신

- 결제 요청이 성공하면 화면은 해당 예약의 SSE 구독을 시작한다.
- S5에서는 1초마다 경과 시간을 갱신하되 이 갱신은 서버 상태를 바꾸지 않는다.
- 푸시를 받으면 1초 이내에 화면이 바뀌어야 한다 (NFR1: 웹훅 수신부터 화면 표시까지).

## 입력 규칙

- 전송 버튼과 엔터 키가 같은 동작을 한다.
- 결제 대기 중에는 새 검색 전송은 허용하되 결제 버튼은 비활성이다. [assumption] 대기 중에도 새 검색은 허용한다는 가정이다.

## 확인 동작

- "이 주차권 결제"는 별도 확인 창 없이 바로 결제를 요청한다. 모의 PG이며 실제 금액이 나가지 않기 때문이다. [assumption]

## 타이머 표시

- 경과 시간은 결제 요청 시점부터 센다 (FR7.1). 180초가 되면 서버가 취소를 확정하고 푸시한다. 화면은 자체 타이머로 취소를 판단하지 않는다.
