# Personas

## 운전자 (주 페르소나, 우선순위 1)

- 역할: 목적지 근처에서 주차권을 구하려는 일반 운전자
- 인증: 로그인 없음. 브라우저 세션 단위의 익명 사용자 ([Q4] 요구사항, FR8.1)
- 목표: 말 한마디(예: "강남역 근처 2시간 주차권 찾아줘")로 조건에 맞는 최적 주차권을 받고, 결제하면 곧바로 예약 완료를 확인한다.
- 불편한 점: 여러 주차장의 요금과 거리를 직접 비교해야 하고, 결제 후 예약이 확정됐는지 불확실하다.
- 사용 맥락: 운전 전이나 이동 중 휴대폰·PC 브라우저에서 짧게 사용한다. 음성은 이미 텍스트로 변환되어 입력된다 (FR1.3).

## 페르소나 관계

페르소나는 하나이며 [Q1] 사용자 선택에 따라 데모 진행자는 두지 않는다. 모의 PG 결제 결과(승인·지연·실패) 선택은 운전자 스토리의 테스트 조건으로 다룬다.
